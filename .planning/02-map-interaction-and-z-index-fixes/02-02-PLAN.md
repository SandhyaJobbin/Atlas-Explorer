  <name>Task 1: Audit deps — wrap volatile props in useRef, split Effect B into per-concern effects</name>

  <action>
    Per D-03 (INTERACT-06/07 root cause): Effect B re-runs on every render where ANY dep changes. `timezoneMap` and `heatmapMap` are object references re-created each render by parent components, causing per-second flicker.

    FIX:
    1. Add useRef wrappers for volatile props before Effect B:
       ```
       const timezoneMapRef = useRef(timezoneMap);
       useEffect(() => { timezoneMapRef.current = timezoneMap; }, [timezoneMap]);
       
       const heatmapMapRef = useRef(heatmapMap);
       useEffect(() => { heatmapMapRef.current = heatmapMap; }, [heatmapMap]);
       
       const defaultFillRef = useRef(defaultFill);
       useEffect(() => { defaultFillRef.current = defaultFill; }, [defaultFill]);
       
       const hoveredTimezoneRef = useRef(hoveredTimezone);
       useEffect(() => { hoveredTimezoneRef.current = hoveredTimezone; }, [hoveredTimezone]);
       ```
       Skip wrapping `mode` — it's a string literal, relatively stable.

    2. Read from `.ref.current` inside Effect B and its rAF callback for these volatile props.

    3. Split Effect B into per-visual-concern effects based on what changes:
       - **Effect B1 (selection state):** deps = [svgContent, activeCode, correctCode, wrongCode, highlightedCodes] — region fill per selection/gameplay state. Removes/adds `is-active`, `is-correct`, `is-wrong`, `is-highlighted` classes.
       - **Effect B2 (heatmap mode):** deps = [svgContent, heatmapMap] — region fill per heatmap values. Adds/removes `is-heatmap` class. Reads `heatmapMapRef.current`.
       - **Effect B3 (mastered/pulsing/cluster):** deps = [svgContent, masteredCodes, pulsingClusterCodes, explorationOrder] — adds/removes `is-mastered`, `is-cluster-pulse`. Reads `modeRef.current` but doesn't depend on it changing.
       - **Effect B4 (timezone hover):** deps = [svgContent, hoveredTimezone] — adds/removes `is-tz-hover`, `is-dimmed`. Reads `timezoneMapRef.current`.
       
       Each effect has its own rAF frameId and cleanup.

    4. For each split effect, apply the same classList diff approach from Plan 02-01 Task 1 (per-element previous-state tracking via Map<element, Set<className>>).

    5. Keep cursor style update (line 296) in B1 since it depends on mode which stays stable.

    Note: All split effects share the same previous-state tracking map to avoid one effect undoing another's classes. Initialize a single `elementClassState = useRef(new Map<SVGPathElement, Set<string>>())` at the component level, shared by all B effects.
